แอพพลิเคชั่นเกม Balance Tower ฟีลเหมือนเป็นเกมฝึกการควบคุมมือ โดยใช้การเอียงโทรศัพท์ (Gyroscope) เพื่อรักษาสมดุลของหอคอย และออกแบบ UI ให้น่าเล่น เข้าใจง่าย และมี feedback กับผู้เล่น
MVP
Feature
- Block Stacking: บล็อกจะตกลงมาจากด้านบน ผู้เล่นต้องควบคุมตำแหน่งเพื่อวางซ้อนกันให้ได้สูงที่สุด ถ้าวางพลาดหรือเอียงมากเกินไปจะล้มและเกมจบ
- Gyroscope Control: ใช้การเอียงมือถือเพื่อควบคุมการเคลื่อนที่ของบล็อกไปทางซ้าย/ขวา ให้รู้สึกเหมือนกำลังรักษาสมดุลจริงๆ
- Touch Control (Fallback): รองรับการควบคุมด้วยการลากหรือปุ่ม สำหรับใช้ทดสอบใน emulator หรือกรณีที่ไม่มี gyro
- Basic Physics: มีแรงตก (gravity) และการวางซ้อนของบล็อกแบบง่าย เมื่อวางแล้วจะกลายเป็นส่วนหนึ่งของหอ
- Score System: คะแนนจะเพิ่มตามจำนวนบล็อกที่วางสำเร็จ และแสดงคะแนนระหว่างเล่นและตอนจบเกม
- Game Over: เมื่อหอเอียงเกินกำหนดหรือบล็อกหลุด จะจบเกมและแสดงผลคะแนน
Event System
- Wind: มีลมพัดแบบสุ่ม ดันหอไปทางซ้ายหรือขวา ทำให้ควบคุมยากขึ้น
- Earthquake: เกิดแผ่นดินไหว ทำให้ฐานหรือหอสั่นไปมา และมีการสั่นของมือถือ (vibration) เพื่อเพิ่มความสมจริง
- Event Indicator: มีข้อความหรือ UI แสดงว่าเกิด event อะไร เช่น “WIND” หรือ “EARTHQUAKE”
Next step
- Increasing Difficulty: เพิ่มความยากตามเวลา เช่น บล็อกตกเร็วขึ้น หรือ event เกิดบ่อยขึ้น
- Different Block Types: มีบล็อกหลายขนาด เช่น ใหญ่ เล็ก หรือบล็อกที่ไม่สมดุล
- Combo / Perfect Placement: ให้คะแนนโบนัสเมื่อวางบล็อกได้ตรงหรือแม่นยำ
- Visual Theme: เปลี่ยนธีมของเกม เช่น สีพื้นหลัง หรือสไตล์ของบล็อก
- Sound Effects: เพิ่มเสียงตอนวางบล็อก ล้ม หรือเกิด event
- Leaderboard: ระบบจัดอันดับคะแนนสูงสุด
- Better Feedback: ปรับปรุง animation เช่น การสั่นของจอ การเอียงของหอ และ UI ที่ตอบสนองต่อการเล่น
